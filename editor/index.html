Editor do portfólio

Se usar um arquivo local, coloque-o na pasta img/ do projeto e referencie como img/nome-do-arquivo.jpg.

Cole o link da matéria e clique em "buscar automaticamente" para tentar preencher veículo, título e foto de capa. Escolha o idioma da matéria — a home mostra até 3 de cada idioma, com link para ver todas. Use as setas para reordenar (a ordem aqui é a mesma exibida no site).

Cole o link (DOI ou página do periódico) e clique em “buscar automaticamente”. Nem todo periódico expõe esses dados — revise sempre.

Funciona bem com links de GitHub — a busca automática costuma preencher nome e descrição do repositório.
